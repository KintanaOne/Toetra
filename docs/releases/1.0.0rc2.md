# Toetra 1.0.0rc2

`1.0.0rc2` extends the V1 release-candidate profile with declarative binary
classification while preserving the regression route and JSON v5 compatibility.

## Added

- typed output schemas and declarative output observables;
- `target[point].label` and `target[point].probability(label)`;
- model-family semantic lowering with auditable evidence;
- direct fitted binary sklearn `LogisticRegression` support;
- certified probability-threshold lowering and pairwise label relations;
- Z3 verification, structured reporting, and concrete sklearn replay;
- self-contained script/notebook demos and a clean-installed-wheel smoke route.

## Fixed

- stable Decimal provenance canonicalization;
- certified interval construction for non-exact logistic thresholds;
- pairwise classification golden fixtures and public-contract alignment.

## Compatibility

- JSON report schema v5 remains additive and backward compatible;
- `LinearRegression` behavior remains unchanged;
- scalar-target compatibility projections remain available through Toetra 1.x.

## Deferred

Multiclass models, threshold/calibration wrappers, symbolic preprocessing,
probability equality, edge thresholds, probability arithmetic, top-k,
abstention, and built-in backends other than Z3 remain outside this release.
