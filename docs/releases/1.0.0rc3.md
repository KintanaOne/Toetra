# Toetra 1.0.0rc3

`1.0.0rc3` completes the public identity cutover from the former development
name to Toetra. It preserves the verification semantics and built-in regression
and binary-classification routes accepted in `1.0.0rc2`.

## Identity cutover

- distribution and public namespace: `toetra`;
- specification language: Toetra Specification Language;
- specification extension: `.toetra`;
- repository and documentation: `KintanaOne/Toetra`;
- review bundle: `toetra_review_bundle.zip`;
- persistent identifiers: `toetra.*`.

No compatibility package or dual extension is provided because no
project-controlled stable release established the former identity as a public
contract.

## Reporting and provenance

- current JSON reports use schema v6 and the
  `toetra.verification-report` identity;
- provenance exposes `toetra_version`, `toetra_build_id`, and
  `TOETRA_BUILD_ID`;
- replay, compatibility, encoder, semantic-target, HTML, text, and artifact
  identifiers use the canonical Toetra identity.

Historical JSON fixtures v1 through v5 remain available as compatibility
records and are not current output contracts.

## Verification scope

The public executable profile is unchanged from `1.0.0rc2`:

- fitted single-output sklearn `LinearRegression`;
- direct fitted binary sklearn `LogisticRegression`;
- finite transformed numeric features;
- affine semantic lowering and Z3 execution;
- structured reporting, provenance, and concrete replay.

## Release gates

The candidate is accepted only when CI, reproducible wheel/sdist construction,
clean-wheel installation, review-bundle reproducibility, and the former-identity
gate are all green.
