Beyond aggregate metrics

Aggregate metrics describe how a model performed on observed data. Toetra asks whether its supported abstraction can violate a behavior you explicitly require.

Not another score. A question over an exact domain.

The verification journey

Intent enters.
Evidence leaves.

The user stays in the vocabulary of model behavior. Toetra keeps compiler details, solver symbols, and framework internals behind explicit boundaries — without hiding how the conclusion was made.

Positive, negative, existential, or inconclusive: Toetra preserves the distinction so an automation pipeline can make an honest decision.

  • Finite transformed numeric features
  • Homogeneous forall and exists
  • Affine arithmetic and Boolean properties
  • Exact-real affine abstractions
  • Z3 execution and capability routing
  • Text, HTML, Jupyter, DataFrame and JSON reports
  • Provenance and concrete model replay
OUTSIDE THE V1 CONTRACT

Toetra does not silently generalize beyond what it can currently support end to end.

  • Multiclass and multi-output models
  • Trees, ensembles and neural networks
  • Symbolic preprocessing reconstruction
  • Calibration and threshold wrappers
  • Alternating quantifiers
  • Built-in non-Z3 backends
  • Bit-exact IEEE-754 equivalence claims
